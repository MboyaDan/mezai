## Bio

I’m a backend engineer based in Nairobi. Since 2018 I’ve run ELS Software Solutions, building production systems in Go and Python for clients in fintech, e-commerce, SaaS and restaurant tech. Much of that work has been payment infrastructure: M-Pesa integrations, webhook verification, and making sure a transaction is recorded exactly once even when the network isn’t cooperating. It’s taught me how East African customers actually write and talk to the systems they use: in Kiswahili, in English, in Sheng, often all three in one message.

I started MezAI because the AI tools now reaching Kenyan users are mostly tested by people who don’t speak the way those users do. A model can pass every English benchmark and still misread “pesa haijaingia.” MezAI gives AI teams human evaluation and labelled data from qualified native speakers, with the quality measured and reported on every batch rather than just promised. I run the process myself, from rubric to delivery, and I work directly with every client.
